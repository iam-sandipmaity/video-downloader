# Code of Conduct

## Our Standard

We want this project to be a welcoming, practical, and respectful place for
everyone who uses, reviews, translates, or contributes to it.

Examples of behavior that help create that environment include:

- being respectful in issues, pull requests, and discussions
- giving clear, constructive, and technically grounded feedback
- assuming good intent while still being honest about bugs and risks
- helping new contributors understand repo conventions
- staying focused on the work instead of turning disagreements into personal attacks

Examples of unacceptable behavior include:

- harassment, threats, or abusive language
- insulting, dismissive, or demeaning comments
- deliberate disruption, trolling, or bad-faith reporting
- publishing someone else's private information without permission
- hostile behavior toward maintainers, contributors, or users

## Scope

This Code of Conduct applies within project spaces, including:

- GitHub issues
- pull requests
- discussions
- review comments
- release notes and documentation threads

It also applies when someone is clearly representing this project in public
project-related spaces.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code,
issues, or other contributions that do not align with this Code of Conduct.

Maintainers may also temporarily or permanently restrict participation from
people whose behavior is repeatedly harmful to the project community.

## Reporting

If you experience or witness unacceptable behavior, report it privately through
the repository's security or maintainer contact path instead of escalating the
conflict publicly.

When possible, include:

- a link or screenshot
- what happened
- when it happened
- any relevant surrounding context

All reports will be reviewed in good faith and handled with reasonable care.

## Project Intent

This repository is centered on practical collaboration:

- stable download behavior
- local-first Android tooling
- respectful issue triage
- high-signal documentation and review

Please help keep the space useful, calm, and constructive.
