# Wiki Source

This folder contains ready-to-publish Markdown for the GitHub wiki of
Video Downloader.

## Suggested Publish Flow

1. Create or clone the repository wiki.
2. Copy every file from this folder into the root of the wiki repo.
3. Keep `Home.md`, `_Sidebar.md`, and `_Footer.md` at the wiki root.
4. Commit and push the wiki repo.

## Notes

- Screenshot pages use raw GitHub image URLs from the main repository.
- Repo policy and release files use full GitHub links so they still work after
  the files are moved into the separate wiki repository.
- Cross-page wiki links in this folder are written as relative Markdown links
  so they work both here in the repo and later in the wiki repo root.
