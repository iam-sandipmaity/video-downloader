# Video Downloader 1.7.2.0

`1.7.2.0` is a security and hardening update focused on safer runtime updates, stricter storage behavior, and tighter handling of sensitive app data.

## Highlights

- Hardened app, `yt-dlp`, and `FFmpeg` update trust and verification
- Tightened handling of saved auth and session data plus diagnostic traces
- Improved WebView safety across preview, cookies, and YouTube access flows
- Aligned Android 10 storage behavior with the newer app-specific staging and public export flow
- Reduced unnecessary shared file exposure

## Fixed

- Removed the insecure certificate-check bypass from the analysis fallback path
- Reduced sensitive local data exposure by moving secrets out of task persistence, tightening logs and exports, and disabling app-data backup
- Added stronger verification for runtime updates, including signer checks and checksum validation
- Hardened WebView trust boundaries and retired the in-app PO-token generator in favor of safer saved-session guidance
- Narrowed `FileProvider` cache exposure to only the directories actually needed for sharing

## Notes

This release is mainly about safety, trust, and internal hardening. User-facing workflows stay largely the same, but the app is now stricter and safer under the hood.
