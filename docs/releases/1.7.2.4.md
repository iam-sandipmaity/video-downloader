# Video Downloader 1.7.2.4

`1.7.2.4` is a stability-focused patch release that tightens download cleanup, public export safety, update coordination, background observer lifecycle handling, and the build-and-release pipeline around the app.

## Highlights

- Hardened paused-download cleanup so expired tasks only remove the files managed for that exact download
- Made Android 10+ public export fail safely when MediaStore cannot provide a writable output stream
- Aligned yt-dlp update blocking across manual and background flows so queued, running, and paused downloads all protect the active runtime
- Reduced memory pressure during large link analysis runs by preferring captured info-json snapshots and capping retained stdout text
- Switched local and CI builds onto the checked-in Gradle wrapper and split Android workflows into clearer build, nightly, stable, and tag-release paths
- Tightened release verification with stronger Kotlin compile, unit test, lint-report, locale-resource, and tagged-release validation coverage

## Fixed

- Paused-download expiry no longer risks deleting similarly named sibling files in the same directory
- Public Downloads export now cleans up failed MediaStore inserts and preserves the private staging copy unless the public write completes successfully
- WorkManager observers for download tasks are now replaced cleanly on retries and resumes instead of lingering after older work stops being relevant
- Large analysis responses now avoid holding unnecessary duplicate JSON text in memory
- Standard JVM and Android compatibility cleanup now covers URI parsing, MediaStore guards, Compose resource reads, locale-safe formatting, and placeholder-aligned translated strings
- Cookie export now reports success and real write failures instead of silently doing nothing when the selected destination stream cannot be opened

## Notes

This release is primarily about making queue recovery, maintenance flows, and release automation more trustworthy under edge conditions rather than adding major new end-user features.
