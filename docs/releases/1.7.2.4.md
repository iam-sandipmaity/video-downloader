# Video Downloader 1.7.2.4

`1.7.2.4` is a stability-focused patch release that tightens download cleanup, public export safety, update coordination, and background observer lifecycle handling.

## Highlights

- Hardened paused-download cleanup so expired tasks only remove the files managed for that exact download
- Made Android 10+ public export fail safely when MediaStore cannot provide a writable output stream
- Aligned yt-dlp update blocking across manual and background flows so queued, running, and paused downloads all protect the active runtime
- Reduced memory pressure during large link analysis runs by preferring captured info-json snapshots and capping retained stdout text

## Fixed

- Paused-download expiry no longer risks deleting similarly named sibling files in the same directory
- Public Downloads export now cleans up failed MediaStore inserts and preserves the private staging copy unless the public write completes successfully
- WorkManager observers for download tasks are now replaced cleanly on retries and resumes instead of lingering after older work stops being relevant
- Large analysis responses now avoid holding unnecessary duplicate JSON text in memory

## Notes

This release is primarily about making queue recovery and maintenance flows more trustworthy under edge conditions rather than adding new end-user features.
