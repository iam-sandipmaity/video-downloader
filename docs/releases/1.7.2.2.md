# Video Downloader 1.7.2.2

`1.7.2.2` is a small follow-up release focused on keeping format selection more honest on muxed-only sites while also closing a release-only build failure in the GitHub pipeline.

## Highlights

- Added a separate `Output transform` step for muxed-only sources so the app can offer `Extract audio` or `Remove audio` without mislabeling native source tabs
- Kept stream-type tabs tied to the real formats returned by yt-dlp, which makes D.tube-style muxed sources, JioSaavn-style audio sources, and X-style mixed sources behave more predictably
- Fixed the release build pipeline by adding the missing `org.tukaani:xz` runtime dependency required by the `commons-compress` code path bundled through `youtubedl-android`

## Fixed

- Muxed-only sources no longer show unavailable native `Audio only` or `Video only` tabs just because the app can derive those outputs later
- Choosing `Remove audio` now performs an actual ffmpeg post-process pass so the saved file matches the requested output
- Format-sheet template and subtitle behavior now follows the effective output type when a derived transform is selected
- `release-main` no longer fails R8 minification on missing `org.tukaani.xz.*` classes

## Notes

This release keeps the stricter source-truthful format model introduced by the recent audio-only classification fixes, but makes the advanced output options clearer for muxed-only sites and restores release pipeline stability at the same time.
